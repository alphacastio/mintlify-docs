Uploads a CSV file. Processing happens in the background. See [Uploading data](/uploading/overview) for the full workflow.

```
PUT https://api.alphacast.io/datasets/{dataset_id}/data
Content-Type: multipart/form-data
```

<span id="authentication" style={{ scrollMarginTop: "8rem" }} />

<span id="request" style={{ scrollMarginTop: "8rem" }} />

Requires [Basic Auth](/authentication) and `Write` permission on the dataset.

## Path parameters

<ParamField path="dataset_id" type="integer" required>Dataset ID.</ParamField>

## Form fields

<ParamField body="data" type="file" required>A CSV file with a header row. You can compress it with gzip. The request limit is 80 MB.</ParamField>
<ParamField body="manifest" type="string">A JSON array that describes the columns. See [Manifest](/uploading/manifest). The first upload to a new dataset needs a manifest, unless you already [initialized the columns](/uploading/overview#before-the-first-upload).</ParamField>

## Query parameters

<ParamField query="deleteMissingFromDB" type="boolean" default="false">Delete existing data that is not in the file.</ParamField>
<ParamField query="onConflictUpdateDB" type="boolean" default="false">Overwrite existing values with the values in the file.</ParamField>
<ParamField query="acceptNewColumns" type="boolean">Allow the file to add new columns.</ParamField>

See [Upload modes](/uploading/validation#upload-modes).

## Response

Returns `201` with the upload process.

<ResponseField name="id" type="integer">Process ID.</ResponseField>
<ResponseField name="status" type="string">Starts at `Requested`.</ResponseField>
<ResponseField name="createdAt" type="string">Creation time.</ResponseField>
<ResponseField name="datasetId" type="integer">Dataset ID.</ResponseField>

## Check an upload process

```
GET /datasets/{dataset_id}/processes/{process_id}
GET /datasets/{dataset_id}/processes
```

Both require `Write` permission. The list returns the 100 newest processes, newest first. Each process has `id`, `datasetId`, `status`, `statusDescription`, `deleteMissingFromDB`, `onConflictUpdateDB`, `createdAt`, and `processedAt`.

Check until `status` is `Processed` or `Error`.

## Example

<RequestExample>

```bash cURL
curl -u YOUR_API_KEY: \
  -X PUT https://api.alphacast.io/datasets/123/data \
  -F "data=@gdp.csv" \
  -F 'manifest=[{"sourceName":"Date","dataType":"Date","isEntity":true,"dateFormat":"%Y-%m-%d"},{"sourceName":"Country","dataType":"String","isEntity":true},{"sourceName":"GDP","dataType":"Decimal","isEntity":false}]'
```

```python Python
import json
import time
import requests

auth = ("YOUR_API_KEY", "")
base = "https://api.alphacast.io/datasets/123"

manifest = [
    {"sourceName": "Date", "dataType": "Date", "isEntity": True, "dateFormat": "%Y-%m-%d"},
    {"sourceName": "Country", "dataType": "String", "isEntity": True},
    {"sourceName": "GDP", "dataType": "Decimal", "isEntity": False},
]

with open("gdp.csv", "rb") as f:
    response = requests.put(
        f"{base}/data",
        auth=auth,
        files={"data": ("gdp.csv", f, "text/csv")},
        data={"manifest": json.dumps(manifest)},
    )
response.raise_for_status()
process_id = response.json()["id"]

for _ in range(120):  # wait up to 10 minutes
    check = requests.get(f"{base}/processes/{process_id}", auth=auth)
    check.raise_for_status()
    process = check.json()
    if process["status"] in ("Processed", "Error"):
        break
    time.sleep(5)

print(process["status"], process["statusDescription"])
```

```javascript Node.js
import { readFile } from "node:fs/promises";

const headers = { Authorization: "Basic " + btoa("YOUR_API_KEY:") };
const base = "https://api.alphacast.io/datasets/123";

const manifest = [
  { sourceName: "Date", dataType: "Date", isEntity: true, dateFormat: "%Y-%m-%d" },
  { sourceName: "Country", dataType: "String", isEntity: true },
  { sourceName: "GDP", dataType: "Decimal", isEntity: false },
];

// fetch sets the multipart Content-Type for FormData
const form = new FormData();
form.append("data", new Blob([await readFile("gdp.csv")], { type: "text/csv" }), "gdp.csv");
form.append("manifest", JSON.stringify(manifest));

const response = await fetch(`${base}/data`, { method: "PUT", headers, body: form });
if (!response.ok) {
  throw new Error(`${response.status}: ${await response.text()}`);
}
const { id } = await response.json();

let result;
for (let i = 0; i < 120; i++) { // wait up to 10 minutes
  const check = await fetch(`${base}/processes/${id}`, { headers });
  if (!check.ok) throw new Error(`${check.status}: ${await check.text()}`);
  result = await check.json();
  if (["Processed", "Error"].includes(result.status)) break;
  await new Promise((resolve) => setTimeout(resolve, 5000));
}

console.log(result.status, result.statusDescription);
```

Replace the data with the content of a compressed file:

```bash
curl -u YOUR_API_KEY: \
  -X PUT "https://api.alphacast.io/datasets/123/data?deleteMissingFromDB=true&onConflictUpdateDB=true" \
  -F "data=@gdp.csv.gz"
```

<Warning>
  `deleteMissingFromDB=true` permanently removes data that is not in the file. Check that the file is complete.
</Warning>

## Error responses

| Status | Cause |
|---|---|
| `400` | The file is missing, the manifest is invalid, or the columns are not initialized. |
| `401` | Missing or invalid API key. |
| `403` | The dataset does not exist for you, or you cannot write to it. |
| `413` | The request is over 80 MB. |
| `503` | The service is temporarily unavailable. If the body has a `processId`, processing may have started. Check that process before you upload again. |

Errors in the data do not change the `201` response. They appear in the process, with status `Error` and a `statusDescription`.
