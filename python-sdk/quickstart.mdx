This guide uploads a small `DataFrame` and downloads it again.

<Note>
  Creating datasets requires a [plan](https://www.alphacast.io/pricing) that lets you create assets. If you only want to read data, go to [Downloading data](/python-sdk/downloading).
</Note>

## Before you start

```bash
pip install alphacast
```

Get your API key from [your settings](https://www.alphacast.io/settings) and save it in the `ALPHACAST_API_KEY` environment variable. See [Authentication](/python-sdk/authentication).

## The script

Save this as `quickstart.py` and run `python quickstart.py`.

```python
import json
import os
import time

import pandas as pd
from alphacast import Alphacast

alphacast = Alphacast(os.environ["ALPHACAST_API_KEY"])

# 1. Create or reuse a repository
repo = alphacast.repository.create(
    "My First Repo",
    repo_description="Sandbox for the SDK quickstart",
    privacy="Private",
    returnIdIfExists=True,
)

# 2. Create or reuse a dataset
dataset = alphacast.datasets.create(
    "Quarterly GDP",
    repo["id"],
    description="GDP series by country",
    returnIdIfExists=True,
)
handle = alphacast.datasets.dataset(dataset["id"])

# 3. Initialize the columns (only before the dataset has data)
if not handle.metadata().get("dataEditedAt"):
    result = json.loads(handle.initialize_columns(
        dateColumnName="Date",
        entitiesColumnNames=["country"],
        dateFormat="%Y-%m-%d",
    ))
    if "columnDefinitions" not in result:
        raise RuntimeError(result)

# 4. Upload a DataFrame
df = pd.DataFrame({
    "Date": ["2023-01-01", "2023-04-01", "2023-07-01"],
    "country": ["USA", "USA", "USA"],
    "GDP_USD_Billions": [6823.4, 6901.2, 6987.6],
})

upload = json.loads(handle.upload_data_from_df(
    df,
    onConflictUpdateDB=True,
    uploadIndex=False,
))
if "id" not in upload or "status" not in upload:
    raise RuntimeError(upload)

# 5. Wait for processing
for _ in range(120):  # up to 10 minutes
    process = json.loads(handle.process(upload["id"]))
    if process["status"] in ("Processed", "Error"):
        break
    time.sleep(5)

if process["status"] != "Processed":
    raise RuntimeError(f"{process['status']}: {process.get('statusDescription')}")

# 6. Download the data
print(handle.download_data(format="pandas").head())
```

## What each step does

- **Create or reuse.** `returnIdIfExists=True` returns the existing repository or dataset with the same name, so you can run the script again.
- **Initialize the columns.** Tells Alphacast which column holds the date and which columns identify each row. You cannot change this with this method after the dataset has data.
- **Upload.** Returns the response as bytes. The upload method does not raise on HTTP errors, so the script checks that the response is a process. If the response is not JSON, `json.loads` raises an error.
- **Wait.** Uploads run in the background. The status starts at `Requested`.
