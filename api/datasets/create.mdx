Creates an empty dataset. Then [upload data](/api/datasets/upload) to it.

```
POST https://api.alphacast.io/datasets
```

<span id="authentication" style={{ scrollMarginTop: "8rem" }} />

<span id="request" style={{ scrollMarginTop: "8rem" }} />

Requires [Basic Auth](/authentication), `Write` permission on the repository, and a plan that lets you create assets. See [pricing](https://www.alphacast.io/pricing).

## Body parameters

<ParamField body="name" type="string" required>Dataset name. It must be unique in the repository. Extra spaces are removed.</ParamField>
<ParamField body="repositoryId" type="integer" required>Repository ID.</ParamField>
<ParamField body="description" type="string">Description of the data.</ParamField>
<ParamField body="sourceName" type="string">Who publishes the original data.</ParamField>
<ParamField body="sourceUrl" type="string">Link to the original data.</ParamField>

## Response

Returns `201` with `id`, `name`, `createdAt`, and `repositoryId`. The response does not include the description or source fields.

## Example

<RequestExample>

```bash cURL
curl -u YOUR_API_KEY: \
  -X POST https://api.alphacast.io/datasets \
  -H "Content-Type: application/json" \
  -d '{
    "name": "US GDP Quarterly",
    "repositoryId": 45,
    "sourceName": "Bureau of Economic Analysis",
    "sourceUrl": "https://www.bea.gov/data/gdp"
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.alphacast.io/datasets",
    auth=("YOUR_API_KEY", ""),
    json={"name": "US GDP Quarterly", "repositoryId": 45},
)
response.raise_for_status()
dataset = response.json()
```

```javascript Node.js
const response = await fetch("https://api.alphacast.io/datasets", {
  method: "POST",
  headers: {
    Authorization: "Basic " + btoa("YOUR_API_KEY:"),
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ name: "US GDP Quarterly", repositoryId: 45 }),
});
if (!response.ok) {
  throw new Error(`${response.status}: ${await response.text()}`);
}
const dataset = await response.json();
console.log(dataset.id);
```

</RequestExample>

## Error responses

| Status | Cause |
|---|---|
| `400` | A required field is missing or invalid. |
| `402` | Your plan does not let you create assets. |
| `403` | The repository does not exist for you, or you cannot write to it. |
| `409` | The name is already taken, or the dataset could not be created. |
