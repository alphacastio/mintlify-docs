title: "Downloading data"
description: "Download datasets as a pandas DataFrame, CSV, JSON, Excel, or TSV, with date, entity, and column filters."
---

Call `download_data()` on a dataset handle.

```python
df = alphacast.datasets.dataset(6755).download_data(format="pandas")
```

To get a dataset ID, use [Search](/python-sdk/search) or open the dataset in the web app and read the ID in the URL.

## Output formats

| `format` | Returns |
|---|---|
| `"pandas"` | `pandas.DataFrame` |
| `"csv"` (default) | CSV bytes |
| `"xlsx"` | Excel bytes |
| `"tsv"` | Tab-separated bytes |
| `"json"` | A list with one object that has `schema` and `data` |

```python
handle = alphacast.datasets.dataset(6755)

with open("data.xlsx", "wb") as f:
    f.write(handle.download_data("xlsx"))

rows = handle.download_data("json")[0]["data"]
```

## Check what you received

Your [plan](https://www.alphacast.io/pricing) controls access. Without full download access to a dataset, you get a **preview**: a limited sample that might not include recent data. If you have used your plan's download allowance, you can get a table with an `error` column instead of data. Neither case raises an exception.

```python
df = handle.download_data(format="pandas")
if list(df.columns) == ["error"]:
    raise RuntimeError(df["error"].iloc[0])
```

<span id="filtering-by-date-range" style={{ scrollMarginTop: "8rem" }} />

## Filter by date

```python
import datetime as dt

df = handle.download_data(
    format="pandas",
    startDate=dt.date(2020, 1, 1),
    endDate=dt.date(2024, 12, 31),
)
```

Use `datetime.date` objects. Both limits are inclusive. The SDK finds the date column. Do not use these arguments on a dataset without one.

<span id="filtering-by-entity-values" style={{ scrollMarginTop: "8rem" }} />

## Filter by entity

```python
df = handle.download_data(
    format="pandas",
    filterEntities={
        "country": ["USA", "Mexico"],
        "sector": ["Manufacturing", "Services"],
    },
)
```

This returns rows where `country` is USA or Mexico **and** `sector` is Manufacturing or Services. Column names are case-sensitive.

<span id="selecting-specific-columns" style={{ scrollMarginTop: "8rem" }} />

## Select columns

```python
df = handle.download_data(
    format="pandas",
    filterVariables=["GDP_USD_Billions", "Inflation_YoY"],
)
```

Date and entity columns are always included. Names must not contain commas.

## Method signature

```python
download_data(
    format="csv",
    startDate=None,
    endDate=None,
    filterVariables=[],
    filterEntities=[],
)
```

You can combine the filters. The server applies them. For the underlying parameters, see [Download data](/api/datasets/data).

A failed request raises `Exception` with the status code.
