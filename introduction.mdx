Alphacast is a platform for economic and financial data. It brings 9,000+ curated datasets from 600+ sources into one place, with particular depth in Latin America. You can query that data from your code or your AI agent, combine it with your own, and build pipelines that keep the results up to date.

These docs are for people who want to **work with Alphacast programmatically**: through the REST API, the Python SDK, or the MCP server. You can also explore the same catalog from the [web app](https://www.alphacast.io/explore) without writing any code.

## What you can do

### Find data

Search the curated Alphacast catalog, which covers areas such as economic activity, prices, labor, fiscal and monetary policy, the external sector, and markets. Datasets are cleaned, structured, and maintained, and they keep a reference to their source.

When you need something outside the catalog, [data providers](/providers/overview) let you query 30+ external sources through one interface, including FRED, the World Bank, the IMF, the OECD, Eurostat, and central banks such as Banxico, BCRA, and BCRP. Some providers require your own API key.

### Add your own data

[Upload your own files](/uploading/overview) to a repository and use them alongside the catalog, with the same API.

### Transform it once, keep it current

A [pipeline](/steps/overview) records every step between the source data and your final output. When a source dataset updates, the pipeline can run again, so the datasets and charts built on it stay current without manual re-exports. You can apply [economic transformations](/steps/transform), [change frequency](/steps/resample), [merge datasets](/steps/merge), run [seasonal adjustment](/steps/arima-sa), or [describe a transformation to AI](/steps/ai-transform).

### Use it where you work

Pull data into notebooks, spreadsheets, BI tools, applications, or AI agents. If a tool can call a REST API, it can read from Alphacast.

## Core concepts

| Concept | What it is |
|---|---|
| [Repository](/concepts/repositories) | A container for datasets that controls who can access them. |
| [Dataset](/concepts/datasets) | A structured table of data, organized by date and by entities such as country or category. |
| [Data provider](/concepts/data-providers) | An external source that you can query through Alphacast. |
| [Pipeline](/steps/overview) | An ordered series of steps that turns source data into an output. |

## Before you start

You need an Alphacast account. The REST API and Python SDK use an [API key](/authentication). The MCP server supports [browser sign-in or an API key](/mcp/authentication), depending on how you connect.
