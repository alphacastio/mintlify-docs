## List providers

```
GET /providers
```

```bash
curl -u YOUR_API_KEY: https://api.alphacast.io/providers
```

Returns an array. Each entry has:

<ResponseField name="slug" type="string">Identifier used in other endpoints.</ResponseField>
<ResponseField name="name" type="string">Name of the data collection.</ResponseField>
<ResponseField name="provider" type="string">Publishing organization.</ResponseField>
<ResponseField name="description" type="string">What the provider covers.</ResponseField>
<ResponseField name="capabilities" type="string[]">`hierarchical`, `search`, `direct`.</ResponseField>
<ResponseField name="license" type="string">License or usage terms.</ResponseField>
<ResponseField name="api_key_required" type="boolean">Whether you need a provider key.</ResponseField>
<ResponseField name="api_key_label" type="string">Name of the key. Can be `null`.</ResponseField>
<ResponseField name="api_key_url" type="string">Where to get the key. Can be `null`.</ResponseField>
<ResponseField name="anonymous_limit_message" type="string">Limits without a key. Can be `null`.</ResponseField>
<ResponseField name="has_user_api_key" type="boolean">Whether you saved a key.</ResponseField>

## Match providers by keyword

```
GET /providers/match?q={keywords}
```

Returns up to five providers whose slug, name, organization, or description match your words. `q` can have up to 256 characters. Results also include `parameters` and `popular_series`. For providers that require a key, they include `api_key_required`, `api_key_label`, `api_key_hint`, and `has_api_key`.

```bash
curl -u YOUR_API_KEY: "https://api.alphacast.io/providers/match?q=argentina+inflation"
```

## Get a provider

```
GET /providers/{slug}
```

Slugs are not case-sensitive. In addition to the list fields, the response includes:

- `parameters`: options you can send when you fetch a series.
- `popular_series`: suggested series, each with `id` and `label`.
- `browse_root_label` and `series_id_placeholder`: hints for browsing and for series ID formats.
- `entity_columns`: extra key columns in the data, if any.

```bash
curl -u YOUR_API_KEY: https://api.alphacast.io/providers/fred
```

## Browse a provider

```
GET /providers/{slug}/browse
```

Works with providers that have the `hierarchical` capability. Others return `400`.

<ParamField query="path" type="string">Position in the tree. Omit it for the root. Path formats differ by provider. Build the path from the values that earlier responses give you.</ParamField>
<ParamField query="depth" type="integer" default="1">Levels to fetch, up to `3`. With a depth above 1, the response has `nodes`, `truncated`, and `depth_reached`.</ParamField>
<ParamField query="limit" type="integer">Page size for series lists, up to 1000. Some folder lists ignore it.</ParamField>
<ParamField query="offset" type="integer">Number of series to skip.</ParamField>

A response with depth 1 usually has a `type`, `items`, and `breadcrumbs`. Folder items have `id` and `name`. Series items have `series_id` and `label`. Other fields depend on the provider.

```bash
curl -u YOUR_API_KEY: https://api.alphacast.io/providers/worldbank/browse
curl -u YOUR_API_KEY: "https://api.alphacast.io/providers/worldbank/browse?path=3&limit=20"
```

```json
{
  "type": "folder_list",
  "items": [
    { "id": "3", "name": "Economy & Growth", "type": "folder" }
  ],
  "breadcrumbs": []
}
```

## Search a provider

```
GET /providers/{slug}/search?q={query}
```

Works with providers that have the `search` capability.

<ParamField query="q" type="string" required>Search text, up to 256 characters.</ParamField>
<ParamField query="limit" type="integer" default="50">Maximum results, up to 1000. A provider can return fewer.</ParamField>
<ParamField query="offset" type="integer">Results to skip, if the provider supports it.</ParamField>

```bash
curl -u YOUR_API_KEY: "https://api.alphacast.io/providers/fred/search?q=unemployment+rate&limit=2"
```

```json
{
  "query": "unemployment rate",
  "limit": 2,
  "has_more": true,
  "items": [
    { "series_id": "UNRATE", "label": "Unemployment Rate", "frequency": "M" },
    { "series_id": "UNRATENSA", "label": "Unemployment Rate", "frequency": "M" }
  ]
}
```

Use `series_id` to [fetch the series](/api/providers/series). Other item fields depend on the provider.

## List your provider keys

```
GET /user-keys
```

Shows which providers have a saved key. It does not return the keys.

{ "fred": true, "bls": true }

## Save a provider key

```
PUT /user-keys/{slug}
```

<ParamField body="api_key" type="string">The key from the provider. Send `null` or an empty string to remove the saved key. A request without this field also removes it.</ParamField>

```bash
curl -u YOUR_API_KEY: \
  -X PUT https://api.alphacast.io/user-keys/fred \
  -H "Content-Type: application/json" \
  -d '{"api_key": "YOUR_FRED_API_KEY"}'
```

```json
{ "slug": "fred", "has_key": true }
```

Follow the provider's `api_key_label` for the format. For example, `bcch` takes `user:password`. For `indec`, check the expiration date of your token in your INDEC account.

You can also manage provider keys in [your settings](https://www.alphacast.io/settings).

## Error responses

| Status | Meaning |
|---|---|
| `400` | Invalid parameter, or the provider does not support the operation. |
| `401` | A key endpoint was called without a valid Alphacast API key. |
| `404` | Provider not found. |
| `429` | The provider's rate limit was reached. |
| `501` | The operation is not implemented for this provider. |
| `502` | The provider or the provider service failed. |

These endpoints report errors in an `error` field. A `401` might not be JSON.
