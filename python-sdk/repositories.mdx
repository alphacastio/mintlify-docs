Every dataset lives in a repository. Use `alphacast.repository` to work with them. See [Repositories](/concepts/repositories) for privacy and permissions.

## List your repositories

```python
for repo in alphacast.repository.read_all():
    print(repo["id"], repo["name"], repo["privacy"], repo["permission"])
```

Returns the repositories that your account or your teams have permission on. Each one has `id`, `name`, `accountId`, `description`, `privacy`, `slug`, and `permission`.

## Get a repository by ID

```python
repo = alphacast.repository.read_by_id(42)
print(repo["name"])
```

<span id="look-up-a-repository-by-name" style={{ scrollMarginTop: "8rem" }} />

## Find a repository by name

```python
repo = alphacast.repository.read_by_name("My First Repo")

if repo:
    print("Found:", repo["id"])
```

The server matches the name, ignoring case and accents. The method returns the first match, which can be a team repository. It returns `False` when nothing matches. If you need an exact target, use the ID.

## Create a repository

```python
repo = alphacast.repository.create(
    "Macro Indicators",
    repo_description="Macroeconomic indicators",
    privacy="Private",
    returnIdIfExists=True,
)
print(repo["id"])
```

<span id="parameters" style={{ scrollMarginTop: "8rem" }} />

<ParamField path="repo_name" type="str" required>Repository name.</ParamField>
<ParamField path="repo_description" type="str">Description. Defaults to the name.</ParamField>
<ParamField path="privacy" type="str" default="Private">`Private` or `Public`.</ParamField>
<ParamField path="slug" type="str">Accepted by the method, but Alphacast generates the slug itself.</ParamField>
<ParamField path="returnIdIfExists" type="bool" default="False">If a repository with this name is found, return it. When `False`, the method raises `ValueError`.</ParamField>

<span id="idempotent-create" style={{ scrollMarginTop: "8rem" }} />

<span id="find-or-create" style={{ scrollMarginTop: "8rem" }} />

With `returnIdIfExists=True`, the method returns the whole repository record, not only the ID. The method raises an exception if the request fails.

## Delete a repository

<Warning>
  This permanently deletes the repository and its content, including datasets, pipelines, charts, and files.
</Warning>

`delete` does not raise on HTTP errors. A successful deletion returns an empty response, so check it:

```python
raw = alphacast.repository.delete(42)
if raw:
    raise RuntimeError(f"Delete failed: {raw.decode()}")
```

## List repositories that you can write to

```python
writable = [
    r for r in alphacast.repository.read_all()
    if r["permission"] in ("Owner", "Admin", "Write")
]
```

To change a repository's name or privacy, use the [web app](/concepts/repositories#repository-settings).
