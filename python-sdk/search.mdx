`alphacast.search.datasets()` searches datasets by keyword.

```python
results = alphacast.search.datasets("inflation Argentina", search_all=True)

for ds in results["data"]:
    print(ds["id"], ds["name"])
```

## Search scope

| Call | Scope |
|---|---|
| Default | Covers only some dataset owners. |
| `search_all=True` | Removes the owner limit. Covers repositories that you can read and Alphacast's public repositories. |
| `repository_id=42` | Covers one repository that you can access. |

To find your own datasets, pass `search_all=True` or the `repository_id` of the repository that holds them. You can also use [`datasets.read_by_name` or `datasets.read_all`](/python-sdk/datasets).

## Parameters

```python
search.datasets(
    query,
    offset=0,
    length=10,
    repository_id=None,
    search_all=False,
    exclude_deprecated=False,
)
```

<ParamField path="query" type="str" required>Search text.</ParamField>
<ParamField path="offset" type="int" default="0">Results to skip.</ParamField>
<ParamField path="length" type="int" default="10">Maximum results.</ParamField>
<ParamField path="repository_id" type="int">Search one repository.</ParamField>
<ParamField path="search_all" type="bool" default="False">Remove the default owner limit.</ParamField>
<ParamField path="exclude_deprecated" type="bool" default="False">Leave out deprecated datasets.</ParamField>

<span id="response-shape" style={{ scrollMarginTop: "8rem" }} />

## Response

A dictionary with `data`, `totalItems`, `totalPages`, `currentPage`, and `offset`. The returned `offset` is the position after the current results. Each result includes `id`, `name`, `repository`, `minDate`, `maxDate`, and other fields.

If the request fails, the method raises `Exception` with the status code.

## Paginate

```python
first = alphacast.search.datasets("inflation", search_all=True, length=10)
second = alphacast.search.datasets("inflation", search_all=True, length=10, offset=10)
```

<span id="search-results-→-download" style={{ scrollMarginTop: "8rem" }} />

## Search and download

```python
results = alphacast.search.datasets("Argentina inflation", search_all=True, length=5)

if results["data"]:
    top = results["data"][0]
    df = alphacast.datasets.dataset(top["id"]).download_data(format="pandas")
```

A search result does not guarantee full download access. See [Plan access to data](/api/datasets/data#plan-access-to-data).
