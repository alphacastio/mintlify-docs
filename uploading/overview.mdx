You add data to a dataset with the API by uploading a CSV file to [`PUT /datasets/{id}/data`](/api/datasets/upload). To upload from the web app instead, see [Your datasets](/your-data/datasets).

<span id="before-you-upload-initialize-the-dataset" style={{ scrollMarginTop: "8rem" }} />

## Before the first upload

[Create the dataset](/api/datasets/create). Then describe its columns in one of two ways.

**Option 1: initialize the columns.**

```bash
curl -X PUT https://api.alphacast.io/datasets/123/columns/initializer \
  -u YOUR_API_KEY: \
  -H "Content-Type: application/json" \
  -d '{
    "dateColumnName": "Date",
    "dateFormat": "%Y-%m-%d",
    "entitiesColumnNames": ["Country"],
    "textVariableNames": ["Notes"]
  }'
```

| Field | Meaning |
|---|---|
| `dateColumnName` | The date column. |
| `dateFormat` | How dates are written, such as `%Y-%m-%d`. |
| `entitiesColumnNames` | Columns that, with the date, identify each row. |
| `textVariableNames` | Value columns that contain text. |

The API returns `201` with the stored `columnDefinitions`. After the dataset has data, this endpoint returns `403`.

**Option 2: send a [manifest](/uploading/manifest) with the upload.**

An upload to a new dataset with neither returns `400`.

## The upload process

Each upload creates a process that runs in the background.

| Status | Meaning |
|---|---|
| `Requested` | The upload was received. Every process starts here. |
| `Processing` | The file is being processed. |
| `Processed` | The upload finished. |
| `Error` | The upload failed. Read `statusDescription`. |

Only one process per dataset runs at a time. If you upload again while a process is running, the new process stays in `Requested` until its turn.

[Check the process](/api/datasets/upload#check-an-upload-process) until it reaches `Processed` or `Error`. Wait for `Processed` before you read the new data.

<span id="file-formats" style={{ scrollMarginTop: "8rem" }} />

## File requirements

- CSV with a header row.
- Plain or gzip-compressed.
- Request size up to 80 MB.
- UTF-8 encoding is recommended.
