A series is one time series taken from a dataset: one value column for a specific combination of entities. Use `alphacast.series(series_id)` with its numeric ID.

## Read metadata

```python
meta = alphacast.series(12345).metadata()

print(meta["datasetId"], meta["frequency"])
print(meta["metadata"]["name"], meta["metadata"]["entities"])
```

The result includes `id`, `datasetId`, `frequency`, and a `metadata` object with `name`, `columnId`, and `entities`.

## Download data

```python
series = alphacast.series(12345)

df = series.download_data(format="pandas")
csv_bytes = series.download_data("csv")
xlsx_bytes = series.download_data("xlsx")
tsv_bytes = series.download_data("tsv")

# JSON: a list with one object that has "schema" and "data"
rows = series.download_data("json")[0]["data"]
```

<ParamField path="format" type="str" default="csv">`csv`, `json`, `xlsx`, `tsv`, or `pandas`.</ParamField>

[Plan access](/api/datasets/data#plan-access-to-data) also applies to series. You can get a preview, or a table with an `error` column, instead of the full data.

<span id="when-to-use-series-vs-datasets" style={{ scrollMarginTop: "8rem" }} />

The series method has no date or column filters. For filtered reads, use [`download_data`](/python-sdk/downloading) on the parent dataset.
