## List datasets

```python
for d in alphacast.datasets.read_all():
    print(d["id"], d["name"], d["repositoryId"], d["permission"])
```

Returns the datasets in repositories that your account or your teams have permission on. It does not list the public catalog. To find catalog datasets, use [Search](/python-sdk/search).

## Find a dataset by name

```python
ds = alphacast.datasets.read_by_name("Quarterly GDP", repo_id=42)

if ds:
    print("Found:", ds["id"])
```

The server matches the name, ignoring case and accents. `repo_id` is optional. Without it, you get the first match in any repository. The method returns `None` when nothing matches.

## Inspect a dataset

```python
handle = alphacast.datasets.dataset(7938)
```

### metadata()

Returns the dataset record, including `id`, `name`, `repositoryId`, `permission`, `frequency`, `minDate`, `maxDate`, `dataEditedAt`, and `columns`. See [Get a dataset](/api/datasets/get).

```python
meta = handle.metadata()
print(meta["name"], meta["maxDate"])
```

### get_column_definitions()

Returns the list of column definitions. Use it after the dataset's columns are set up.

```python
for c in handle.get_column_definitions():
    print(c.get("sourceName"), c.get("dataType"), c.get("isEntity"))
```

### datestats()

Returns the frequency and date range as JSON bytes.

```python
import json

stats = json.loads(handle.datestats())
print(stats["inferedFreq"], stats["minDate"], stats["maxDate"])
```

The field name is spelled `inferedFreq`.

## Delete a dataset

<Warning>
  Deletion is permanent.
</Warning>

`delete` does not raise on HTTP errors. A successful deletion returns an empty response, so check it:

```python
raw = handle.delete()
if raw:
    raise RuntimeError(f"Delete failed: {raw.decode()}")
```

A dataset that is still in use is not deleted. See [conflicts](/api/datasets/delete#conflicts). The SDK has no option to force the deletion.
