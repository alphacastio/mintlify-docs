Updating a repository is not currently available through the REST API. Change its name, description, or privacy in the web app.

## Update a repository in the web app

Open the repository and go to its **Settings** tab. Admins see this tab. Your personal home repository does not have one. Who can change privacy depends on the role.

See [Repository settings](/concepts/repositories#repository-settings) and [Privacy](/concepts/repositories#privacy).
