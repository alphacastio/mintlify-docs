Alphacast connects to external data providers through one set of endpoints. You can browse a provider, search it, and fetch series without learning each provider's own API. In the web app, use the [API Explorer](/explore/api-explorer).

  **alphacast.io/explore/apis** is the authoritative list of providers, popular series, and key requirements. It can change before this page does.
</Card>

Slugs are not case-sensitive. **API key** refers to the provider's own key, which is separate from your Alphacast API key.

## Fetch your first series

Authenticate with your Alphacast API key. This example uses `bcra`, which needs no provider key.

<Steps>
  <Step title="List providers">
    <span id="listing-all-providers" style={{ scrollMarginTop: "8rem" }} />

    ```bash
    curl -u YOUR_API_KEY: https://api.alphacast.io/providers
    ```
  </Step>
  <Step title="Inspect a provider">
    ```bash
    curl -u YOUR_API_KEY: https://api.alphacast.io/providers/bcra
    ```
  </Step>
  <Step title="Search">
    <span id="browsing-hierarchically" style={{ scrollMarginTop: "8rem" }} />

    <span id="searching-a-provider" style={{ scrollMarginTop: "8rem" }} />

    ```bash
    curl -u YOUR_API_KEY: "https://api.alphacast.io/providers/bcra/search?q=reservas"
    ```
  </Step>
  <Step title="Fetch a series">
    <span id="fetching-a-fred-series" style={{ scrollMarginTop: "8rem" }} />

    Use a series ID from the search results or from `popular_series`.

    ```bash
    curl -u YOUR_API_KEY: https://api.alphacast.io/providers/bcra/series/1
    ```
  </Step>
</Steps>

## Provider keys

Some providers need a key that you get from them. Save it once, either in [your settings](https://www.alphacast.io/settings) or with [`PUT /user-keys/{slug}`](/api/providers/list#save-a-provider-key). Alphacast then uses it for your requests.

## Keep provider data current

A provider request returns data at the time of the request. To save a series and refresh it, use the [Fetch API Provider step](/steps/fetch-api-provider) in a pipeline.
