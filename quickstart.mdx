---
title: "Get started with the Alphacast API"
sidebarTitle: "Quickstart"
description: "Get your API key, create a repository and a dataset, upload a CSV file, and download the data."
---

This guide takes you through the core workflow of the REST API with `curl`. Replace the sample IDs with the IDs from your own responses.

<Note>
  API access is available on every plan. Catalog access and download volume depend on your plan. Creating datasets also requires a plan that lets you create assets. Otherwise the API returns `402`. See [pricing](https://www.alphacast.io/pricing).
</Note>

<Steps>
  <Step title="Get your API key">
    Open [your settings](https://www.alphacast.io/settings). Next to **API Key**, click **Show Key**.

    Send the key as the HTTP Basic Auth username, with an empty password. The trailing colon tells `curl` that the password is empty.

    ```bash
    curl https://api.alphacast.io/repositories \
      -u YOUR_API_KEY:
    ```
  </Step>

  <Step title="Create a repository">
    Every dataset belongs to a repository.

    ```bash
    curl -X POST https://api.alphacast.io/repositories \
      -u YOUR_API_KEY: \
      -H "Content-Type: application/json" \
      -d '{"name": "My First Repository", "privacy": "Private"}'
    ```

    The API returns `201`:

    ```json
    {
      "id": 42,
      "name": "My First Repository",
      "description": null,
      "privacy": "Private",
      "slug": "my-first-repository-42"
    }
    ```
  </Step>

  <Step title="Create a dataset">
    ```bash
    curl -X POST https://api.alphacast.io/datasets \
      -u YOUR_API_KEY: \
      -H "Content-Type: application/json" \
      -d '{"name": "Quarterly GDP", "repositoryId": 42}'
    ```

    The API returns `201`:

    ```json
    {
      "id": 101,
      "name": "Quarterly GDP",
      "createdAt": "2026-01-15T10:30:00",
      "repositoryId": 42
    }
    ```
  </Step>

  <Step title="Initialize the columns">
    Before the first upload, tell Alphacast which column holds the date and which columns, with the date, identify each row.

    ```bash
    curl -X PUT https://api.alphacast.io/datasets/101/columns/initializer \
      -u YOUR_API_KEY: \
      -H "Content-Type: application/json" \
      -d '{
        "dateColumnName": "Date",
        "dateFormat": "%Y-%m-%d",
        "entitiesColumnNames": ["Country"]
      }'
    ```

    You can instead send a [manifest](/uploading/manifest) with your first upload. An upload to a new dataset with neither returns `400`.
  </Step>

  <Step title="Upload a CSV file">
    Save this as `gdp.csv`:

    ```csv
    Date,Country,GDP_USD_Billions
    2023-01-01,USA,6823.4
    2023-04-01,USA,6901.2
    2023-07-01,USA,6987.6
    ```

    Then upload it:

    ```bash
    curl -X PUT https://api.alphacast.io/datasets/101/data \
      -u YOUR_API_KEY: \
      -F "data=@gdp.csv"
    ```

    The API returns `201` with an upload process:

    ```json
    {
      "id": 500,
      "status": "Requested",
      "createdAt": "2026-01-15T10:31:00",
      "datasetId": 101
    }
    ```
  </Step>

  <Step title="Wait for processing">
    Uploads are processed in the background. Check the process until `status` is `Processed` or `Error`.

    ```bash
    curl https://api.alphacast.io/datasets/101/processes/500 \
      -u YOUR_API_KEY:
    ```

    If the status is `Error`, read `statusDescription`.
  </Step>

  <Step title="Download the data">
    The default format is CSV. Use `-L` because the API can answer with a redirect.

    ```bash
    curl -L https://api.alphacast.io/datasets/101/data \
      -u YOUR_API_KEY: \
      --output gdp_download.csv
    ```

    Choose another format with `$format`. Put the URL in single quotes so your shell does not expand `$format`.

    <CodeGroup>

    ```bash JSON
    curl -L 'https://api.alphacast.io/datasets/101/data?$format=json' \
      -u YOUR_API_KEY:
    ```

    ```bash XLSX
    curl -L 'https://api.alphacast.io/datasets/101/data?$format=xlsx' \
      -u YOUR_API_KEY: \
      --output gdp.xlsx
    ```

    ```bash TSV
    curl -L 'https://api.alphacast.io/datasets/101/data?$format=tsv' \
      -u YOUR_API_KEY:
    ```

    </CodeGroup>

    To filter, select columns, or paginate, see [Download data](/api/datasets/data).
  </Step>
</Steps>
