The **Alphacast Python SDK** is a Python client for Alphacast. Use it to:

- Download datasets into a `pandas.DataFrame`.
- Upload a `DataFrame` or CSV.
- Create repositories and datasets, and check upload processes.
- Search datasets.

## Installation

```bash
pip install alphacast
```

The package installs `requests`, `pandas`, and `python-dotenv`. The source code is on [GitHub](https://github.com/Alphacastio/alphacast-python-sdk).

## Initialize the client

Find your API key in [your settings](https://www.alphacast.io/settings). Next to **API Key**, click **Show Key**.

```python
import os
from alphacast import Alphacast

alphacast = Alphacast(os.environ["ALPHACAST_API_KEY"])
```

| Attribute | Use it to |
|---|---|
| `alphacast.repository` | List, get, create, and delete repositories. |
| `alphacast.datasets` | List and create datasets, and open a dataset to read, upload, or delete it. |
| `alphacast.search` | Search datasets. |
| `alphacast.series(id)` | Read one series. |

<Note>
  Catalog access and download volume depend on your [plan](https://www.alphacast.io/pricing). Creating datasets also requires a plan that lets you create assets.
</Note>

<Warning>
  Some write methods do not raise an exception when a request fails. See [Check write results](/python-sdk/reference#check-write-results).
</Warning>
