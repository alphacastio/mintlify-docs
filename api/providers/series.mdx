Send your Alphacast API key with [Basic Auth](/authentication). If the provider needs its own key, [save it first](/api/providers/list#save-a-provider-key).

## Fetch a series with GET

```
GET /providers/{slug}/series/{series_id}
```

You can send provider parameters in the query string.

<ParamField path="slug" type="string" required>Provider slug.</ParamField>
<ParamField path="series_id" type="string" required>Series ID. The format depends on the provider. Some IDs contain `/`. Keep those slashes in the URL.</ParamField>

<RequestExample>

```bash cURL
curl -u YOUR_API_KEY: \
  https://api.alphacast.io/providers/bcra/series/1
```

```python Python
import requests

response = requests.get(
    "https://api.alphacast.io/providers/bcra/series/1",
    auth=("YOUR_API_KEY", ""),
)
response.raise_for_status()
series = response.json()
print(series["label"], len(series["data"]))
```

</RequestExample>

## Fetch a series with POST

```
POST /providers/{slug}/series/{series_id}/data
```

Use this form to send provider parameters in a JSON body.

<ParamField body="params" type="object">Provider parameters. See the `parameters` field of [`GET /providers/{slug}`](/api/providers/list#get-a-provider).</ParamField>

```bash
curl -u YOUR_API_KEY: \
  -X POST https://api.alphacast.io/providers/fred/series/UNRATE/data \
  -H "Content-Type: application/json" \
  -d '{"params": {"units": "pc1", "frequency": "a"}}'
```

FRED parameters include `units`, `frequency`, `observation_start`, and `observation_end`. Parameters differ for each provider.

Other examples:

| Provider | Parameter | Meaning |
|---|---|---|
| `bls` | `startyear`, `endyear` | First and last year, such as `2015` and `2024`. |
| `worldbank` | `country` | Country code, such as `BR`. Separate several codes with commas. The default is `all`. |
| `worldbank` | `date_range` | Years as `start:end`, such as `2000:2024`. |

```bash
curl -u YOUR_API_KEY: \
  -X POST https://api.alphacast.io/providers/worldbank/series/NY.GDP.PCAP.CD/data \
  -H "Content-Type: application/json" \
  -d '{"params": {"country": "BR", "date_range": "2000:2024"}}'
```

Without your own BLS key, you are limited to 25 requests per day. You can [save a key](/api/providers/list#save-a-provider-key).

## Response

<ResponseField name="series_id" type="string">The requested ID.</ResponseField>
<ResponseField name="label" type="string">Series name.</ResponseField>
<ResponseField name="metadata" type="object">Provider details, such as frequency or units. It includes `total_observations`.</ResponseField>
<ResponseField name="data" type="object[]">Observations. They usually have `date` and `value`.</ResponseField>
<ResponseField name="entity_columns" type="string[]">Extra key columns in each observation, if any.</ResponseField>

<ResponseExample>

```json 200
{
  "series_id": "1",
  "label": "Reservas Internacionales del BCRA",
  "metadata": { "series_id": "1", "total_observations": 7603 },
  "data": [
    { "date": "1996-01-02", "value": 17314 },
    { "date": "1996-01-03", "value": 17404 }
  ],
  "entity_columns": []
}
```

</ResponseExample>

The example is shortened. Large series can produce large responses. Use the provider's date parameters to narrow the request.

## Error responses

| Status | Meaning |
|---|---|
| `400` | Invalid request. |
| `404` | Provider or series not found. |
| `429` | The provider's rate limit was reached. |
| `501` | The operation is not implemented for this provider. |
| `502` | The provider request failed. If the provider needs a key, check that you saved a valid one. |

These errors use an `error` field.

## FRED shortcut endpoints

If you work only with FRED, you can also use two shorter endpoints. Send your Alphacast API key with [Basic Auth](/authentication). These endpoints do not use your saved FRED key.

<span id="get-/fred/search/" style={{ scrollMarginTop: "8rem" }} />

<span id="param-query" style={{ scrollMarginTop: "8rem" }} />

### Search FRED

```
GET /fred/search/{query}
```

Returns an object with a `results` array of up to 10 matching FRED series. Each result has the fields that FRED provides, such as `id`, `title`, `frequency`, and `units`.

```bash
curl -u YOUR_API_KEY: https://api.alphacast.io/fred/search/unemployment
```

<span id="get-/fred//data" style={{ scrollMarginTop: "8rem" }} />

### Download a FRED series

```
GET /fred/{symbol}/data
```

<ParamField path="symbol" type="string" required>FRED series code, such as `UNRATE` or `CPIAUCSL`.</ParamField>
<ParamField query="$format" type="string" default="csv">`csv`, `json`, `xlsx`, or `tsv`. JSON has a `schema` and a `data` array.</ParamField>
<ParamField query="$top" type="integer">Return only the last N observations.</ParamField>
<ParamField query="start" type="string">First date, as `YYYY-MM-DD`.</ParamField>
<ParamField query="end" type="string">Last date, as `YYYY-MM-DD`. The default is today.</ParamField>

The data has a `Date` column and a column named after the series. Put the URL in single quotes so your shell does not expand `$format` and `$top`.

```bash
curl -u YOUR_API_KEY: \
  'https://api.alphacast.io/fred/UNRATE/data?$format=json&$top=12'
```

```bash
curl -u YOUR_API_KEY: \
  'https://api.alphacast.io/fred/CPIAUCSL/data?start=2020-01-01&end=2023-12-31' \
  --output cpi.csv
```
