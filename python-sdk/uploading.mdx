Uploading has three steps: create the dataset, describe its columns, and upload. For the rules, see [Uploading data](/uploading/overview).

## 1. Create the dataset

```python
ds = alphacast.datasets.create(
    "Quarterly GDP",
    repo_id=42,
    description="GDP series by country",
    returnIdIfExists=True,
)
handle = alphacast.datasets.dataset(ds["id"])
```

If a dataset with that name exists in the repository, `returnIdIfExists=True` returns its record. Otherwise the method raises `ValueError`. It raises `Exception` if the request fails, for example when your [plan](https://www.alphacast.io/pricing) does not let you create datasets.

## 2. Describe the columns

Before the first upload, use `initialize_columns` or [declare the columns in the upload](#declare-columns-in-the-upload).

```python
import json

raw = handle.initialize_columns(
    dateColumnName="Date",
    entitiesColumnNames=["country"],
    dateFormat="%Y-%m-%d",
)
if "columnDefinitions" not in json.loads(raw):
    raise RuntimeError(raw.decode())
```

All three arguments are required. The method does not raise for every HTTP error, so check the result. It works only before the dataset has data.

## 3. Upload

```python
raw = handle.upload_data_from_df(
    df,
    onConflictUpdateDB=True,
    uploadIndex=False,
)
```

<span id="from-a-csv-string" style={{ scrollMarginTop: "8rem" }} />

Or upload a CSV string:

```python
with open("gdp.csv", encoding="utf-8") as f:
    raw = handle.upload_data_from_csv(f.read(), onConflictUpdateDB=True)
```

The SDK compresses the CSV with gzip. `upload_data_from_df` raises an error for an empty `DataFrame`.

<ParamField path="uploadIndex" type="bool" default="True">Only for DataFrames. Set `False` unless the index holds data, such as dates.</ParamField>

<span id="return-value" style={{ scrollMarginTop: "8rem" }} />

## Check the response

<Warning>
  The upload methods do not raise on HTTP errors. Check every response.
</Warning>

```python
def check_upload(raw):
    try:
        body = json.loads(raw)
    except ValueError:
        raise RuntimeError(raw.decode(errors="replace"))
    if "id" not in body or "status" not in body:
        raise RuntimeError(body)
    return body

process = check_upload(raw)
print(process["id"], process["status"])  # status starts at Requested
```

If the error body has a `processId`, processing may have started. [Check that process](/python-sdk/processes) before you upload again.

A valid response only means that the upload was accepted. [Wait for the process](/python-sdk/processes#wait-for-an-upload) to finish.

## Merge flags

<ParamField path="deleteMissingFromDB" type="bool" default="False">Delete existing data that is not in the upload.</ParamField>
<ParamField path="onConflictUpdateDB" type="bool" default="False">Overwrite existing values with uploaded values.</ParamField>
<ParamField path="acceptNewColumns" type="bool" default="None">Set `True` to allow new columns.</ParamField>

See [Upload modes](/uploading/validation#upload-modes).

<span id="inline-schema-declaration" style={{ scrollMarginTop: "8rem" }} />

## Declare columns in the upload

You can send a [manifest](/uploading/manifest) with the upload:

```python
raw = handle.upload_data_from_df(
    df,
    uploadIndex=False,
    dateColumnName="Date",
    dateFormat="%Y-%m-%d",
    entitiesColumnNames=["country"],
    stringColumnNames=["notes"],
)
process = check_upload(raw)
```

- `dateColumnName` and `dateFormat` go together. If you omit one, the date column is left out of the manifest.
- `entitiesColumnNames` are text columns that identify each row.
- `stringColumnNames` are value columns with text.
- The SDK does not add numeric value columns to the manifest.
