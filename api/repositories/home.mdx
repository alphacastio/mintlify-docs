Returns your personal **Home** repository. Use its `id` when you want to save datasets or pipelines there. Create requests still need an explicit `repositoryId`.

```
GET https://api.alphacast.io/repositories/home
```

## Response

The same fields as [Get a repository](/api/repositories/get). If there is no Home repository, the API returns `404`.

<span id="example" style={{ scrollMarginTop: "8rem" }} />

<RequestExample>

```bash cURL
curl -u YOUR_API_KEY: https://api.alphacast.io/repositories/home
```

```python Python
import requests

home = requests.get(
    "https://api.alphacast.io/repositories/home",
    auth=("YOUR_API_KEY", ""),
).json()
print(home["id"])
```

</RequestExample>

## Get the default repository of a workspace

```
GET https://api.alphacast.io/repositories/default
```

Returns the default writable repository for the workspace of your API key. This can be your [working repository](/concepts/repositories#choose-your-working-repository). In your personal workspace, it falls back to Home. A team workspace with no usable default returns `404`.

```bash
curl -u YOUR_API_KEY: https://api.alphacast.io/repositories/default
```
