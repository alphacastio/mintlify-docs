```
GET https://api.alphacast.io/datasets/{dataset_id}
```

<span id="authentication" style={{ scrollMarginTop: "8rem" }} />

<span id="endpoints" style={{ scrollMarginTop: "8rem" }} />

<span id="get-dataset-metadata" style={{ scrollMarginTop: "8rem" }} />

Requires [Basic Auth](/authentication). You can get datasets in repositories that you have permission on, and in public repositories.

## Path parameters

<ParamField path="dataset_id" type="integer" required>Dataset ID.</ParamField>

## Response

<span id="param-description" style={{ scrollMarginTop: "8rem" }} />

<ResponseField name="id" type="integer">Dataset ID.</ResponseField>
<ResponseField name="name" type="string">Dataset name.</ResponseField>
<ResponseField name="createdAt" type="string">Creation time.</ResponseField>
<ResponseField name="updatedAt" type="string">Last metadata update.</ResponseField>
<ResponseField name="dataEditedAt" type="string">Last data update. Can be `null`.</ResponseField>
<ResponseField name="frequency" type="string">Frequency code, such as `D`, `M`, `Q`, or `A`. Can be `null`.</ResponseField>
<ResponseField name="minDate" type="string">First date. Can be `null`.</ResponseField>
<ResponseField name="maxDate" type="string">Last date. Can be `null`.</ResponseField>
<ResponseField name="repositoryId" type="integer">Repository ID.</ResponseField>
<ResponseField name="permission" type="string">Your permission: `Owner`, `Admin`, `Write`, `Clone`, or `Read`.</ResponseField>
<ResponseField name="pipelineId" type="integer">Linked pipeline. Can be `null`.</ResponseField>
<ResponseField name="tags" type="object[]">Tags, each with `id` and `name`.</ResponseField>
<span id="param-source-name" style={{ scrollMarginTop: "8rem" }} />

<span id="param-source-url" style={{ scrollMarginTop: "8rem" }} />

<ResponseField name="source" type="object">Data source with `id` and `name`. Can be `null`.</ResponseField>
<ResponseField name="publication" type="object">Publication with `id` and `name`. Can be `null`.</ResponseField>
<ResponseField name="columns" type="object[]">
  Columns of the dataset. Empty before the first upload is processed.

  <Expandable title="column properties">
    <ResponseField name="id" type="integer">Column ID. You can use it in `$select`.</ResponseField>
    <ResponseField name="name" type="string">Column name.</ResponseField>
    <ResponseField name="dataType" type="string">`Date`, `String`, or `Decimal`.</ResponseField>
    <ResponseField name="isEntity" type="integer">`1` for date and entity columns, `0` for value columns.</ResponseField>
  </Expandable>
</ResponseField>

## Example

<RequestExample>

```bash cURL
curl -u YOUR_API_KEY: https://api.alphacast.io/datasets/123
```

```python Python
import requests

response = requests.get(
    "https://api.alphacast.io/datasets/123",
    auth=("YOUR_API_KEY", ""),
)
response.raise_for_status()
dataset = response.json()
print(dataset["name"], dataset["maxDate"], [c["name"] for c in dataset["columns"]])
```

```javascript Node.js
const headers = { Authorization: "Basic " + btoa("YOUR_API_KEY:") };

const response = await fetch("https://api.alphacast.io/datasets/123", { headers });
if (!response.ok) {
  throw new Error(`${response.status}: ${await response.text()}`);
}
const dataset = await response.json();
```

## Rename or move a dataset

```
PUT https://api.alphacast.io/datasets/{dataset_id}
```

Requires [Basic Auth](/authentication) and `Admin` or `Owner` permission on the dataset.

<ParamField body="name" type="string" required>The new name. To move a dataset without renaming it, send its current name.</ParamField>
<ParamField body="repositoryId" type="integer">Repository to move the dataset to. You need `Write` permission on it. That repository cannot already have a dataset with the same name.</ParamField>

This endpoint does not change tags. A request with a `tags` field returns `400`.

Returns `201` with `id`, `name`, and `updateAt`. The field name is spelled `updateAt`.

Rename a dataset:

```bash
curl -u YOUR_API_KEY: \
  -X PUT https://api.alphacast.io/datasets/123 \
  -H "Content-Type: application/json" \
  -d '{"name": "US GDP, quarterly"}'
```

To move it to another repository, add `repositoryId`:

```bash
curl -u YOUR_API_KEY: \
  -X PUT https://api.alphacast.io/datasets/123 \
  -H "Content-Type: application/json" \
  -d '{"name": "US GDP, quarterly", "repositoryId": 46}'
```

If you rename a dataset to a name that its repository already uses, the API returns `409` with the code `dataset_name_taken`.
