```
DELETE https://api.alphacast.io/datasets/{dataset_id}
```

<span id="authentication" style={{ scrollMarginTop: "8rem" }} />

<span id="request" style={{ scrollMarginTop: "8rem" }} />

Requires [Basic Auth](/authentication) and `Write` permission on the dataset.

<Warning>
  Deletion is permanent.
</Warning>

<span id="path-parameters" style={{ scrollMarginTop: "8rem" }} />

## Parameters

<ParamField path="dataset_id" type="integer" required>Dataset ID.</ParamField>
<ParamField query="allowBreakingConsumers" type="string">Send `true` to delete a dataset that pipelines read. Those pipelines stop working.</ParamField>

## Response

Returns `204` with an empty body.

<span id="error-responses" style={{ scrollMarginTop: "8rem" }} />

## Conflicts

The API returns `409` with a `code` when the dataset is still in use.

| `code` | What to do |
|---|---|
| `dataset_published_by_pipeline` | Remove the step that publishes to the dataset, or delete that pipeline. Then retry. |
| `dataset_has_series` | You cannot delete this dataset. |
| `dataset_has_consumers` | Review the pipelines that read it. To delete anyway, send `allowBreakingConsumers=true`. |
| `dataset_has_dependencies` | Other content still uses the dataset. |

A `403` means that you cannot write to the dataset, or that it does not exist for you.

## Example

<RequestExample>

```bash cURL
curl -u YOUR_API_KEY: -X DELETE https://api.alphacast.io/datasets/123
```

```python Python
import requests

response = requests.delete(
    "https://api.alphacast.io/datasets/123",
    auth=("YOUR_API_KEY", ""),
)
response.raise_for_status()
```

```javascript Node.js
const headers = { Authorization: "Basic " + btoa("YOUR_API_KEY:") };

const response = await fetch("https://api.alphacast.io/datasets/123", {
  method: "DELETE",
  headers,
});
if (!response.ok) {
  throw new Error(`${response.status}: ${await response.text()}`);
}
// Success is 204 with an empty body
```

</RequestExample>

<ResponseExample>

```json 409
{
  "message": "2 pipeline(s) use this dataset and will stop working if it is deleted. Confirm to delete it anyway.",
  "code": "dataset_has_consumers",
  "details": { "datasetId": 123, "consumersCount": 2 }
}
```

</ResponseExample>
