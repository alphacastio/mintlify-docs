<span id="how-the-sdk-uses-your-key" style={{ scrollMarginTop: "8rem" }} />

The SDK uses your Alphacast API key. You give it once, when you create the client.

<Warning>
  Treat your API key like a password. Do not commit it, share it, or put it in client-side code.
</Warning>

## Get your API key

Open [your settings](https://www.alphacast.io/settings). Next to **API Key**, click **Show Key**.

## Initialize the client

```python
from alphacast import Alphacast

alphacast = Alphacast("YOUR_API_KEY")
```

To use a second key, create a second client.

<span id="recommended-read-from-an-environment-variable" style={{ scrollMarginTop: "8rem" }} />

## Read the key from an environment variable

<CodeGroup>

```bash macOS / Linux
export ALPHACAST_API_KEY="your-key-here"
```

```powershell Windows (PowerShell)
$env:ALPHACAST_API_KEY = "your-key-here"
```

</CodeGroup>

```python
import os
from alphacast import Alphacast

alphacast = Alphacast(os.environ["ALPHACAST_API_KEY"])
```

<span id="loading-from-a-env-file" style={{ scrollMarginTop: "8rem" }} />

## Use a .env file

The SDK installs `python-dotenv`. Add a `.env` file:

```
ALPHACAST_API_KEY=your-key-here
```

```python
import os
from dotenv import load_dotenv
from alphacast import Alphacast

load_dotenv()
alphacast = Alphacast(os.environ["ALPHACAST_API_KEY"])
```

<Tip>
  Add `.env` to your `.gitignore`.
</Tip>

<span id="errors" style={{ scrollMarginTop: "8rem" }} />

## Authentication errors

Creating the client does not check the key. Read methods raise an exception on a failed request. For an invalid key, the message includes the status code:

```
Exception: API failed with status code 401
```

Check that you copied the whole key without extra spaces and that it is your current key. In settings, **Reset** creates a new key. Scripts that use the old key can stop working.

Some write methods and `search.datasets` behave differently. See [Check write results](/python-sdk/reference#check-write-results) and [Search](/python-sdk/search).
