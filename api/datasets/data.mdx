```
GET https://api.alphacast.io/datasets/{dataset_id}/data
```

<span id="param-api-key" style={{ scrollMarginTop: "8rem" }} />

Use [Basic Auth](/authentication). This endpoint also accepts `?apiKey=`, for tools that cannot send headers.

<span id="request" style={{ scrollMarginTop: "8rem" }} />

## Path parameters

<ParamField path="dataset_id" type="integer" required>Dataset ID.</ParamField>

## Query parameters

<ParamField query="$format" type="string" default="csv">`csv`, `json`, `xlsx`, or `tsv`.</ParamField>
<ParamField query="$select" type="string">Comma-separated column names or column IDs. Date and entity columns are always included. Example: `$select=GDP,Inflation`.</ParamField>
<ParamField query="$filter" type="string">Rows to return. See [Filter rows](#filter-rows).</ParamField>
<ParamField query="$top" type="integer">Return up to the first N rows, after filtering.</ParamField>
<ParamField query="$skip" type="integer">Skip N rows. Use it with `$top` to paginate. You cannot combine it with `versionId`.</ParamField>
<ParamField query="$last" type="integer">Return up to N rows from the most recent dates. Without a date column, it returns the first N rows. You cannot combine it with `$top`.</ParamField>
<ParamField query="$combineEntities" type="boolean">Combine entity columns into one column. The result can be empty when there are too many combinations. Omit the parameter to turn it off.</ParamField>
<ParamField query="includeIds" type="boolean">Include column IDs in the output.</ParamField>
<ParamField query="dropNA" type="boolean">With `$select`, drop rows where the selected value columns are all empty.</ParamField>
<ParamField query="transpose" type="boolean">Transpose the table, with dates as columns. If a transposed CSV is not available for the dataset or version, the API returns `409`.</ParamField>
<ParamField query="versionId" type="string">Download a specific stored version of the data.</ParamField>

Other parameters that start with `$` return `400`.

## Response

The API returns the file directly or answers with a `302` redirect to a short-lived download link. Always follow redirects (`curl -L`). Do not save the redirect link for later, because it expires quickly.

When the API returns the file directly, the `Content-Type` header matches the format:

| `$format` | `Content-Type` |
|---|---|
| `csv` | `text/csv` |
| `json` | `application/json` |
| `xlsx` | `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet` |
| `tsv` | `text/tab-separated-values` |

CSV output can start with a UTF-8 byte order mark. In Python, decode it with `utf-8-sig`.

<span id="row-count-response-header" style={{ scrollMarginTop: "8rem" }} />

With `$top` or `$last`, the `Row-Count` response header gives the number of matching rows before the limit, when available.

### JSON format

`$format=json` returns an object with a `schema` and a `data` array:

```json
{
  "schema": { "fields": [ { "name": "Date", "type": "datetime" }, { "name": "GDP", "type": "number" } ] },
  "data": [
    { "Date": "2025-01-01T00:00:00.000", "GDP": 100.5 }
  ]
}
```

## Plan access to data

Your plan decides which catalog datasets you can download in full. See [pricing](https://www.alphacast.io/pricing).

- If your plan does not include full download of a dataset, the API returns a **preview** instead of an error. A preview is a limited sample and might not include the most recent data.
- If you have used your plan's download allowance, the response can be a file with an `error` column and an upgrade message instead of data.

In automated jobs, check the content of the file, not only the status code.

## Filter rows

| Operator | Meaning | Example |
|---|---|---|
| `eq` | Equal | `Country eq 'USA'` |
| `gt`, `ge` | Greater than, greater than or equal | `Date ge '2020-01-01'` |
| `lt`, `le` | Less than, less than or equal | `Date le '2024-12-31'` |
| `and`, `or` | Combine conditions | `Country eq 'USA' or Country eq 'Canada'` |

- These are the supported operators.
- Column names are case-sensitive. A name that does not exist returns `400` with the list of columns.
- Put string values in single quotes. For a column name with spaces, put the name in single quotes too.
- Values are compared as text. This works for entity values and `YYYY-MM-DD` dates. Do not rely on `gt` or `lt` for numbers.

## Examples

<RequestExample>

```bash cURL
curl -L -u YOUR_API_KEY: \
  https://api.alphacast.io/datasets/123/data \
  --output data.csv
```

```python Python
import requests

response = requests.get(
    "https://api.alphacast.io/datasets/123/data",
    params={"$format": "csv", "$filter": "Country eq 'USA'"},
    auth=("YOUR_API_KEY", ""),
)
response.raise_for_status()
with open("data.csv", "wb") as f:
    f.write(response.content)
```

```javascript Node.js
import { writeFile } from "node:fs/promises";

const headers = { Authorization: "Basic " + btoa("YOUR_API_KEY:") };
const params = new URLSearchParams({ $format: "csv", $filter: "Country eq 'USA'" });

// fetch follows redirects by default
const response = await fetch(`https://api.alphacast.io/datasets/123/data?${params}`, { headers });
if (!response.ok) {
  throw new Error(`${response.status}: ${await response.text()}`);
}
await writeFile("data.csv", Buffer.from(await response.arrayBuffer()));
```

</RequestExample>

Filter rows. `--data-urlencode` encodes the spaces and quotes. The backslash keeps the shell from expanding `$filter`.

```bash
curl -L -G -u YOUR_API_KEY: \
  https://api.alphacast.io/datasets/123/data \
  --data-urlencode "\$filter=Country eq 'USA' and Date ge '2020-01-01'" \
  --data-urlencode "\$format=json"
```

Select columns:

```bash
curl -L -u YOUR_API_KEY: \
  'https://api.alphacast.io/datasets/123/data?$select=GDP'
```

Get the second page of 100 rows:

```bash
curl -L -u YOUR_API_KEY: \
  'https://api.alphacast.io/datasets/123/data?$top=100&$skip=100'
```

## Error responses

| Status | Cause |
|---|---|
| `400` | Invalid filter or column, unsupported `$` parameter, or `$top` combined with `$last`. |
| `401` | Missing or invalid API key. |
| `403` | The dataset does not exist or you cannot read it. |
| `409` | A transposed file is not available. |
