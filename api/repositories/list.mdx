Returns the repositories that your own account or your teams have permission on. It does not list every public repository.

```
GET https://api.alphacast.io/repositories
```

<span id="request" style={{ scrollMarginTop: "8rem" }} />

<span id="authentication" style={{ scrollMarginTop: "8rem" }} />

Requires [Basic Auth](/authentication).

## Query parameters

<ParamField query="name" type="string">Return only repositories with this name. The match ignores case and accents. Returns up to 100 results. An empty value returns `400`.</ParamField>

## Response

A JSON array, ordered by your permission level and then by ID.

<ResponseField name="id" type="integer">Repository ID.</ResponseField>
<ResponseField name="name" type="string">Repository name.</ResponseField>
<ResponseField name="accountId" type="integer">Account that owns the repository.</ResponseField>
<ResponseField name="description" type="string">Description. Can be `null`.</ResponseField>
<span id="param-team" style={{ scrollMarginTop: "8rem" }} />

<ResponseField name="privacy" type="string">`Public` or `Private`.</ResponseField>
<ResponseField name="slug" type="string">URL-friendly identifier.</ResponseField>
<ResponseField name="permission" type="string">Your highest permission: `Owner`, `Admin`, `Write`, `Clone`, or `Read`.</ResponseField>

## Example

<RequestExample>

```bash cURL
curl -u YOUR_API_KEY: https://api.alphacast.io/repositories
```

```python Python
import requests

response = requests.get(
    "https://api.alphacast.io/repositories",
    params={"name": "Emerging Markets Macro"},  # optional
    auth=("YOUR_API_KEY", ""),
)
repositories = response.json()
```

</RequestExample>

<ResponseExample>

```json 200
[
  {

```

</ResponseExample>
