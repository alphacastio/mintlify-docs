The Alphacast Model Context Protocol (MCP) server lets AI assistants and coding agents work with Alphacast through structured tool calls. They can search the curated catalog, read dataset rows, load your Workspace's analytical methodologies, browse external data providers, look up market tickers, and build data pipelines.

## Two ways to connect

The same 35 tools are available through two transports. Pick whichever fits your client and environment. A few data tools behave differently: for large results, the hosted server can return temporary download links and the local server can save files on your machine.

<CardGroup cols={2}>
  <Card title="Hosted (remote)" icon="cloud">
    Point your client at `https://mcp.alphacast.io/mcp`. Nothing to install — no Node.js, no npm, no API key. You sign in once through your browser with **OAuth** and your Alphacast account. Best for most users and for clients that support remote MCP servers.
  </Card>
  <Card title="Local (npm)" icon="terminal">
    Your client spawns the `@alphacast/mcp` package as a local subprocess via `npx -y @alphacast/mcp` over stdio. Requires Node.js 18+ and an `ALPHACAST_API_KEY`. Best for CI, saving large results to local files, or clients that don't yet support remote servers or OAuth.
  </Card>
</CardGroup>

| | Hosted (remote) | Local (npm) |
|---|---|---|
| Endpoint | `https://mcp.alphacast.io/mcp` | `npx -y @alphacast/mcp` (stdio) |
| Requirements | A browser to sign in | Node.js 18+ installed |
| Authentication | OAuth (browser login) | `ALPHACAST_API_KEY` env var |
| Tools | 35 | 35 |
| Large results | Bounded rows and temporary download links | Local temporary files |

Both authenticate as your Alphacast account and respect the same repository permissions. API and MCP access is available on every plan, including Free and Explorer. Catalog access and download volume depend on your [plan](https://www.alphacast.io/pricing). Creating pipelines requires a plan that can create content. See [Authentication](/mcp/authentication) for the details of each, then follow the [Quickstart](/mcp/quickstart) or your client's [configuration guide](/mcp/configuration/claude-code).

## Tool availability and write access

- There are no tools to delete repositories, datasets or whole pipelines.
- Six tools need the `mcp:write` scope on the hosted server: the four pipeline editing tools, plus `get_step_preview` and `get_step_data`. The last two can start pipeline runs. See [Safety boundaries](/mcp/tools/overview#safety-boundaries).
- If your Workspace has catalog exploration turned off, the server omits the catalog search, external provider and ticker tools, and lists 26 tools. See [Tool availability](/mcp/tools/overview#tool-availability).
- You manage provider API keys in [Alphacast settings](https://www.alphacast.io/settings).
