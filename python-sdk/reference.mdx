## Errors

<span id="conventions" style={{ scrollMarginTop: "8rem" }} />

Read methods, `search.datasets`, and the `create` methods raise `Exception` for failed requests. The `create` methods raise `ValueError` when the item already exists and `returnIdIfExists=False`.

## Check write results

These methods return the raw response and do not raise for all HTTP errors. Check the result.

| Method | Success looks like |
|---|---|
| `upload_data_from_df`, `upload_data_from_csv` | JSON with `id` and `status`. Then [wait for the process](/python-sdk/processes#wait-for-an-upload). |
| `initialize_columns` | JSON with `columnDefinitions` |
| `dataset(id).delete()` | Empty bytes |
| `repository.delete(id)` | Empty bytes |

An error response might not be JSON, so `json.loads` can raise `ValueError`.
