Each upload creates a process that runs in the background. A status is `Requested` at first, and ends as `Processed` or `Error`. It can show `Processing` while it runs. See [The upload process](/uploading/overview#the-upload-process).

## List processes

`processes()` returns JSON bytes with the 100 newest processes of the dataset, newest first. You need `Write` permission.

```python
import json

handle = alphacast.datasets.dataset(7938)

for p in json.loads(handle.processes())[:5]:
    print(p["id"], p["status"], p.get("statusDescription"))
```

| Field | Meaning |
|---|---|
| `id` | Process ID |
| `datasetId` | Dataset ID |
| `status` | Current status |
| `statusDescription` | Result or error details |
| `deleteMissingFromDB` | Flag used for the upload |
| `onConflictUpdateDB` | Flag used for the upload |
| `createdAt` | When it was submitted |
| `processedAt` | When processing finished |

<span id="get-a-single-process" style={{ scrollMarginTop: "8rem" }} />

## Get one process

```python
record = json.loads(handle.process(45141))
print(record["status"], record.get("statusDescription"))
```

Both methods raise `Exception` if the request fails.

## Wait for an upload

```python
import json
import time

def wait_for_upload(handle, process_id, timeout=600):
    deadline = time.time() + timeout
    while time.time() < deadline:
        record = json.loads(handle.process(process_id))
        if record["status"] == "Processed":
            return record
        if record["status"] == "Error":
            raise RuntimeError(record.get("statusDescription"))
        time.sleep(5)
    raise TimeoutError(f"Process {process_id} did not finish in time")
```

Get `process_id` from the [upload response](/python-sdk/uploading#check-the-response).
