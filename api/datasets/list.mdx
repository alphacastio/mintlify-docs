Returns the datasets in repositories that your own account or your teams have permission on. It does not list the public catalog.

```
GET https://api.alphacast.io/datasets
```

<span id="authentication" style={{ scrollMarginTop: "8rem" }} />

<span id="request" style={{ scrollMarginTop: "8rem" }} />

Requires [Basic Auth](/authentication).

## Query parameters

<ParamField query="name" type="string">Return only datasets with this name. The match ignores case and accents. Returns up to 100 results. An empty value returns `400`.</ParamField>
<ParamField query="repositoryId" type="integer">Return only datasets in this repository.</ParamField>

## Response

A JSON array, ordered by your permission level and then by ID.

<ResponseField name="id" type="integer">Dataset ID.</ResponseField>
<ResponseField name="name" type="string">Dataset name.</ResponseField>
<ResponseField name="createdAt" type="string">Creation time.</ResponseField>
<ResponseField name="updatedAt" type="string">Last metadata update.</ResponseField>
<ResponseField name="dataEditedAt" type="string">Last data update. Can be `null`.</ResponseField>
<ResponseField name="repositoryId" type="integer">Repository ID.</ResponseField>
<ResponseField name="permission" type="string">Your permission: `Owner`, `Admin`, `Write`, `Clone`, or `Read`.</ResponseField>

## Example

<RequestExample>

```bash cURL
curl -u YOUR_API_KEY: \
  "https://api.alphacast.io/datasets?repositoryId=45"
```

```python Python
import requests

response = requests.get(
    "https://api.alphacast.io/datasets",
    params={"repositoryId": 45, "name": "CPI Monthly"},
    auth=("YOUR_API_KEY", ""),
)
datasets = response.json()
```

```javascript Node.js
const headers = { Authorization: "Basic " + btoa("YOUR_API_KEY:") };
const params = new URLSearchParams({ repositoryId: "45" });

const response = await fetch(`https://api.alphacast.io/datasets?${params}`, { headers });
if (!response.ok) {
  throw new Error(`${response.status}: ${await response.text()}`);
}
const datasets = await response.json();
```
