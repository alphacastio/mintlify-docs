Returns the column definitions of a dataset. Use it to check column names before you write a `$select` or `$filter`.

```
GET https://api.alphacast.io/datasets/{dataset_id}/columns
```

<span id="authentication" style={{ scrollMarginTop: "8rem" }} />

<span id="request" style={{ scrollMarginTop: "8rem" }} />

Requires [authentication](/authentication) and read access to the dataset. This endpoint also accepts `?apiKey=`.

## Path parameters

<ParamField path="dataset_id" type="integer" required>Dataset ID.</ParamField>

## Response

An object with a `columnDefinitions` array. For a dataset with data, each entry has:

<ResponseField name="id" type="integer">Column ID. You can use it in `$select`.</ResponseField>
<ResponseField name="name" type="string">Column name.</ResponseField>
<ResponseField name="sourceName" type="string">Same value as `name`.</ResponseField>
<ResponseField name="destinationName" type="string">Same value as `name`.</ResponseField>
<ResponseField name="dataType" type="string">`Date`, `String`, or `Decimal`.</ResponseField>
<ResponseField name="isEntity" type="integer">`1` for date and entity columns, `0` for value columns.</ResponseField>

Before the first upload is processed, the endpoint returns the definitions that you [initialized](/uploading/overview#before-the-first-upload). Those entries can have different fields. Call this endpoint only after you set up the columns.

<span id="examples" style={{ scrollMarginTop: "8rem" }} />

## Example

<RequestExample>

```bash cURL
curl -u YOUR_API_KEY: https://api.alphacast.io/datasets/123/columns
```

```python Python
import requests

response = requests.get(
    "https://api.alphacast.io/datasets/123/columns",
    auth=("YOUR_API_KEY", ""),
)
columns = response.json()["columnDefinitions"]
```

</RequestExample>

<ResponseExample>

```json 200
{
  "columnDefinitions": [
    { "id": 1, "name": "Date", "sourceName": "Date", "destinationName": "Date", "dataType": "Date", "isEntity": 1 },
    { "id": 3, "name": "GDP", "sourceName": "GDP", "destinationName": "GDP", "dataType": "Decimal", "isEntity": 0 }
  ]
}
```

</ResponseExample>

## Error responses

| Status | Cause |
|---|---|
| `401` | Missing or invalid API key. |
| `403` | The dataset does not exist or you cannot read it. |
