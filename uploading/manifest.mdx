A manifest is a JSON array that describes the columns of a CSV file. Send it as the `manifest` form field of an [upload](/api/datasets/upload).

## Manifest shape

```json
[
  { "sourceName": "Date",    "dataType": "Date",    "isEntity": true, "dateFormat": "%Y-%m-%d" },
  { "sourceName": "Country", "dataType": "String",  "isEntity": true },
  { "sourceName": "GDP_USD", "dataType": "Decimal", "isEntity": false, "destinationName": "GDP" },
  { "sourceName": "Internal", "dataType": "String", "isEntity": false, "ignore": true }
]
```

## Column fields

Every entry needs `sourceName`, `dataType`, and `isEntity`, including ignored columns. Otherwise the API returns `400` with `Manifest is not correctly formatted`.

<ParamField body="sourceName" type="string" required>The column name in the CSV header.</ParamField>
<ParamField body="dataType" type="string" required>`Date`, `String` (text), or `Decimal` (numbers). Other values are not accepted.</ParamField>
<ParamField body="isEntity" type="boolean" required>`true` for columns that identify a row, including the date. `false` for values. Use a JSON boolean, not a string.</ParamField>
<ParamField body="dateFormat" type="string">For the date column: a `strftime` format, such as `%Y-%m-%d` or `%d/%m/%Y`.</ParamField>
<ParamField body="destinationName" type="string">A new name for the column in the dataset.</ParamField>
<ParamField body="ignore" type="boolean">`true` to leave the column out.</ParamField>

## How column names are matched

- `destinationName` and `ignore` apply to the column whose header is the same as `sourceName`. Spaces at the start and end of a header are removed first.
- A column with `ignore: true` must be in the file. Otherwise the upload fails.
- After renaming, Alphacast matches headers to column names without regard to case, accents, or spaces. For example, `pais` matches `País`.

## Entity and value columns

- **Entity columns**, together with the date, form the key of each row. Typical examples are `Country`, `Sector`, or `Ticker`.
- **Value columns** hold the measurements.

Each combination of date and entity values must appear only once in a file. If you have several measurements for the same date and country, add an entity column that tells them apart.

<span id="date-format" style={{ scrollMarginTop: "8rem" }} />

## The date column

Use one column with `dataType` set to `Date` and `isEntity` set to `true`. Write every date in the same format, and match it with `dateFormat`.
If you leave `dateFormat` out of a manifest, Alphacast uses `%Y-%m-%d`.

Extra text after the date, such as a time, is accepted. For example, `2024-01-01 00:00:00` matches `%Y-%m-%d`. If a date does not match, the upload fails with `Date should be formatted as <format>`.

<span id="numeric-type-inference" style={{ scrollMarginTop: "8rem" }} />

## Number columns

Alphacast checks the values of each value column that is not declared as `String`.

- Write decimals with a dot or a comma, such as `1200.5` or `1200,5`.
- Do not use thousands separators. A comma can be read as a decimal separator, so `1,200` can be stored as `1.2`. Values such as `1,200.50` or `1.200,50` are not read as numbers.
- A `%` sign at the end of a value is removed. If every row in the column ends with `%`, the numbers are also divided by 100, so `12.5%` is stored as `0.125`. If any row has no `%` sign, including an empty row, the numbers are not divided.
- A column with text values is numeric if more than 80% of its non-empty values can be read as numbers. The other values become empty. Otherwise the whole column is stored as text, and this does not make the upload fail.

To keep codes or labels as text, declare the column as `String`.

## Rename and ignore columns

For this file:

```csv
Fecha,País,PIB,Notas_Internas
2024-01-01,Argentina,621.4,reviewed
```

this manifest renames three columns and leaves one out:

```json
[
  { "sourceName": "Fecha", "destinationName": "Date",    "dataType": "Date",    "isEntity": true, "dateFormat": "%Y-%m-%d" },
  { "sourceName": "País",  "destinationName": "Country", "dataType": "String",  "isEntity": true },
  { "sourceName": "PIB",   "destinationName": "GDP",     "dataType": "Decimal", "isEntity": false },
  { "sourceName": "Notas_Internas", "dataType": "String", "isEntity": false, "ignore": true }
]
```

## Saved definitions

When an upload succeeds, Alphacast saves the manifest you sent with the dataset.

<Warning>
  A new manifest that removes an entity column replaces the whole dataset with the new file. See [upload modes](/uploading/validation#upload-modes).
</Warning>
