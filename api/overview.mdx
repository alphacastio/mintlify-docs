Use the REST API to manage repositories and datasets, upload and download data, and query external data providers.

## Base URL

```
https://api.alphacast.io
```

## Authentication

Send your API key as the HTTP Basic Auth username, with an empty password.

```bash
curl -u YOUR_API_KEY: https://api.alphacast.io/repositories
```

Most endpoints require Basic Auth. See [Authentication](/authentication) for the `apiKey` query parameter.

## Plans

API access is available on every plan, including Free and Explorer. Catalog access and download volume depend on your plan. Creating datasets requires a plan that lets you create assets. See [pricing](https://www.alphacast.io/pricing).

## Request format

Send JSON bodies with `Content-Type: application/json`. [Data uploads](/api/datasets/upload) use `multipart/form-data`. The request body limit is 80 MB.

## Query parameters that start with $

Some parameters start with `$`, such as `$format`. In a shell, put the URL in single quotes so the shell does not expand them.

```bash
curl -L -u YOUR_API_KEY: \
  'https://api.alphacast.io/datasets/123/data?$format=xlsx' \
  --output data.xlsx
```

<span id="data-export-formats" style={{ scrollMarginTop: "8rem" }} />

## Export formats

[Download data](/api/datasets/data) accepts these `$format` values:

| Format | Value |
|--------|-------|
| CSV | `csv` (default) |
| JSON | `json` |
| Excel | `xlsx` |
| Tab-separated | `tsv` |

## Pagination

| Endpoint | How to limit results |
|---|---|
| `GET /repositories` | No pagination. `name` returns up to 100 matches. |
| `GET /datasets` | No pagination. Filter with `repositoryId` or `name`. `name` returns up to 100 matches. |
| `GET /datasets/{id}/data` | `$top`, `$skip`, `$last`, `$filter` |
| Provider browse and search | `limit` and `offset`, where the provider supports them |

## Retrying requests

<span id="rate-limits" style={{ scrollMarginTop: "8rem" }} />

Do not retry a `POST` or an upload blindly. If you lose the response, first check whether the request succeeded. Repository names are unique within an account, and dataset names within a repository, so repeating a successful create returns `409`.

## Provider rate limits

External data providers have their own limits. When you reach one, a provider endpoint can return `429`. For some providers you can [save your own provider key](/api/providers/list#save-a-provider-key). Without your own key, BLS allows 25 requests per day.
