```
GET https://api.alphacast.io/repositories/{repository_id}
```

<span id="request" style={{ scrollMarginTop: "8rem" }} />

<span id="authentication" style={{ scrollMarginTop: "8rem" }} />

<span id="errors" style={{ scrollMarginTop: "8rem" }} />

Requires [Basic Auth](/authentication). You can get repositories that you have permission on, and public repositories.

## Path parameters

<ParamField path="repository_id" type="integer" required>Repository ID.</ParamField>

## Response

<ResponseField name="id" type="integer">Repository ID.</ResponseField>
<ResponseField name="name" type="string">Repository name.</ResponseField>
<ResponseField name="accountId" type="integer">Account that owns the repository.</ResponseField>
<ResponseField name="description" type="string">Description. Can be `null`.</ResponseField>
<span id="param-team" style={{ scrollMarginTop: "8rem" }} />

<ResponseField name="privacy" type="string">`Public` or `Private`.</ResponseField>
<ResponseField name="slug" type="string">URL-friendly identifier.</ResponseField>
<ResponseField name="permission" type="string">Your permission: `Owner`, `Admin`, `Write`, `Clone`, or `Read`.</ResponseField>

## Example

<RequestExample>

```bash cURL
curl -u YOUR_API_KEY: https://api.alphacast.io/repositories/101
```

```python Python
import requests

response = requests.get(
    "https://api.alphacast.io/repositories/101",
    auth=("YOUR_API_KEY", ""),
)
response.raise_for_status()
repository = response.json()
print(repository["name"], repository["permission"])
```

</RequestExample>

<ResponseExample>

```json 200
{
  "id": 101,
  "name": "Emerging Markets Macro",
  "accountId": 12,
  "description": "GDP, inflation, and rates",
  "privacy": "Private",
  "slug": "emerging-markets-macro-101",
  "permission": "Owner"

```

```json 404
{ "message": "Repository 101 doesn't exist" }
```

</ResponseExample>
