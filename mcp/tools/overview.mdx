## Safety boundaries

<Warning>
  Six tools need write access (the `mcp:write` scope on the hosted server):

  - `create_pipeline`, `add_pipeline_step`, `edit_pipeline_step` and `delete_pipeline_step` change pipelines. Saving a change also runs the pipeline.
  - `get_step_preview` cancels runs of that pipeline that are processing and starts a preview run.
  - `get_step_data` can start a full pipeline run for some Data Snapshot steps. It needs both `mcp:read` and `mcp:write`.
</Warning>

A pipeline run can fetch external data and run the pipeline's output steps. For example, a publish step writes to its dataset. Review a change before you ask your assistant to make it.

There are no tools to delete repositories, datasets or whole pipelines. You manage provider API keys in [Alphacast settings](https://www.alphacast.io/settings).

## Tool availability

If your Workspace has catalog exploration turned off, the server omits nine tools and lists 26:

- `search_catalog`
- `list_providers`, `get_provider`, `browse_provider`, `search_provider`, `get_series`
- `search_tickers`, `get_ticker`, `get_ticker_data`

Workspace, dataset, repository, chart and pipeline tools remain available. On the hosted server, a change to this setting starts a new session. On the local server, restart it to pick up the change.

## Tool conventions

- **IDs** are numeric. Most tools also accept numbers sent as strings.
- **Formats:** `download_dataset` and `get_ticker_data` default to `json`. `get_step_data` defaults to `csv`.
- **Permissions:** your repository permissions and your [plan](https://www.alphacast.io/pricing) determine which calls succeed.
- **Default repository:** when `create_pipeline` or `list_pipelines` has no `repositoryId`, the server uses your default writable repository.

## Underlying API

The tools call Alphacast services on your behalf. You don't need to call any endpoint yourself. To write your own code against Alphacast, see the [API overview](/api/overview).
